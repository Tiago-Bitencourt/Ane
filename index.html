Extrator de Dados PDF

Leia a tabela de um PDF escaneado, revise os dados e preencha seu CSV automaticamente.

  1. 1

    Enviar o PDF

    O texto é lido por OCR, página a página. Pode levar alguns segundos por página.

  2. 2

    Revisar os dados

    Confira os campos destacados e corrija clicando na célula. Enter confirma.

    Os dados aparecem aqui depois que o PDF for processado.

  3. 3

    Preencher o CSV

    O CSV precisa de uma coluna de ID. Somente as células vazias são preenchidas.
